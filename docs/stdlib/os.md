# Operating system

[Reference index](README.md) · [Official Lua 5.2 OS library](https://www.lua.org/manual/5.2/manual.html#6.9) · [C Lua 5.2.4 source](https://www.lua.org/source/5.2/loslib.c.html) · [Implementation](../../src/Lua/Standard/OperatingSystemLibrary.cs)

Install with `state.OpenOperatingSystemLibrary()`. Time, environment, process exit, and filesystem operations are routed through `LuaPlatform` providers where indicated. Default providers use .NET APIs; Unity/custom providers can behave differently.

| API / official reference | Inputs and result | Lua-CSharp implementation notes and differences |
| --- | --- | --- |
| [`os.clock()`](https://www.lua.org/manual/5.2/manual.html#pdf-os.clock) | Returns elapsed CPU time in seconds. | **Host-dependent:** calls `ILuaOsEnvironment.GetTotalProcessorTime`. The default reads the current .NET process's total processor time, including host work outside Lua. |
| [`os.date([format [, time]])`](https://www.lua.org/manual/5.2/manual.html#pdf-os.date) | Formats a timestamp, or returns date fields for `*t`; a leading `!` selects UTC. Defaults to current time and `%c`. Explicit timestamps are truncated toward zero to whole Unix seconds, as in C Lua 5.2. | Uses managed date/time formatting and the configured `TimeProvider.LocalTimeZone` rather than C `strftime`/process timezone state. Names and composite formats use the C-locale conventions below. |
| [`os.difftime(t2, t1)`](https://www.lua.org/manual/5.2/manual.html#pdf-os.difftime) | Returns `t2 - t1` in seconds. | Direct double subtraction preserves fractions instead of converting to C `time_t` first. **Limitation:** both arguments are required; C Lua 5.2.4 also accepts an omitted/nil second argument as zero, although the manual lists both arguments. |
| [`os.execute([command])`](https://www.lua.org/manual/5.2/manual.html#pdf-os.execute) | Officially runs a shell command or queries shell availability. | **Unsupported operation:** no command/nil returns false; supplying a command raises a not-supported error. The library has no shell-execution implementation. |
| [`os.exit([code [, close]])`](https://www.lua.org/manual/5.2/manual.html#pdf-os.exit) | Requests termination with a numeric code or boolean success/failure code. Numeric strings are coerced and fractions truncated toward zero to a managed 32-bit code. | **Host-dependent:** default `SystemOsEnvironment` calls `Environment.Exit`; Unity uses its application exit provider. **Limitation:** `close` is ignored, so the Lua state is not explicitly disposed before exiting. |
| [`os.getenv(name)`](https://www.lua.org/manual/5.2/manual.html#pdf-os.getenv) | Returns an environment value or nil. | **Host-dependent:** default provider reads process environment variables; custom/Unity providers may expose a managed dictionary instead. Names/results are converted between byte strings and .NET text when needed. |
| [`os.remove(filename)`](https://www.lua.org/manual/5.2/manual.html#pdf-os.remove) | Removes a path or reports failure. | **Limitation:** default `FileSystem.Remove` removes files only, even on POSIX hosts where C Lua can remove empty directories. It uses `File.Exists`/`File.Delete` and has no directory-removal path. Handled errors use .NET HResult codes. |
| [`os.rename(oldname, newname)`](https://www.lua.org/manual/5.2/manual.html#pdf-os.rename) | Moves/renames a file or directory; reports success or handled failure. | **Host-dependent:** default provider uses `File.Move`/`File.Replace` and `Directory.Move`. Directory replacement restrictions follow .NET/host filesystem behavior rather than C `rename`; .NET Standard 2.1 uses `File.Replace` for an existing file destination. |
| [`os.setlocale(locale [, category])`](https://www.lua.org/manual/5.2/manual.html#pdf-os.setlocale) | Officially selects or queries a C locale. | **Limitation:** only the literal `C` is accepted; other strings return nil, nil is not a locale-query operation, and `category` is ignored. No C or .NET locale is changed. Date formatting stays invariant; string casing/classification follows the [string library's rules](string.md). |
| [`os.time([table])`](https://www.lua.org/manual/5.2/manual.html#pdf-os.time) | Without a table, returns current Unix seconds. With a table, converts local date fields; defaults are hour 12, minute/second 0. The input table remains unchanged, as in C Lua 5.2.4. `isdst` disambiguates repeated local times; see below. | **Limitation:** fields must be integral and fit the .NET `DateTime` constructor; fractional fields are rejected instead of truncated, and out-of-range dates are rejected instead of normalized by C `mktime`. Current time and the local timezone come from `TimeProvider`, consistently with `os.date`. |
| [`os.tmpname()`](https://www.lua.org/manual/5.2/manual.html#pdf-os.tmpname) | Returns a temporary pathname. | **Host-dependent:** default `Path.GetTempFileName` creates an empty file while choosing the name. The caller owns cleanup; unlike `io.tmpfile`, this API does not attach delete-on-close behavior. The name uses the state's string representation. |

## Date conversion details

The date formatter implements a managed mapping of [POSIX `strftime` conversions](https://man7.org/linux/man-pages/man3/strftime.3p.html). It uses fixed C-locale forms rather than the host C locale. The following conversions are recognized:

`%a %A %b %B %c %C %d %D %e %F %g %G %h %H %I %j %m %M %n %p %r %R %S %t %T %u %U %V %w %W %x %X %y %Y %z %Z %%`

Formatting rules and remaining differences:

- `%U` and `%W` count weeks starting on Sunday and Monday respectively, with days before the first such day in week 00. `%V`, `%g`, and `%G` use the ISO week number and week-based year. These POSIX conversions are available here even when a non-POSIX C Lua build rejects them.
- `%z` emits a signed offset as `HHMM`, without a colon. `%Z` emits `UTC` for UTC and the configured timezone's .NET standard/daylight name otherwise; these names can differ from C runtime abbreviations. Both omitted and explicit timestamps use the same timezone rules.
- Month/day names are invariant English. `%c` uses `ddd MMM dd HH:mm:ss yyyy` with a space-padded day, `%x` uses `MM/dd/yy`, `%X` uses `HH:mm:ss`, and `%r` uses `hh:mm:ss AM/PM`. These follow POSIX C-locale forms; a particular C runtime's locale-dependent composites can differ. Changing `os.setlocale` has no effect.
- Valid POSIX `%E`/`%O` modifiers use the same C-locale conversions as their unmodified forms: `%E` accepts `cCxXyY`, and `%O` accepts `deHImMSuUVwWy`. Unknown conversions and invalid/incomplete modifier pairs raise an error.

Timestamp conversion is bounded by .NET date/time ranges. For byte-string states, format literals remain byte-string units and managed timezone names are encoded as text. Use the official link for the complete Lua/C contract and this list for the implemented behavior.

During a repeated local hour, a truthy `isdst` selects the daylight-saving occurrence and false selects standard time. Nil/omitted `isdst` uses .NET's standard-time default for ambiguous dates. This preserves `os.time(os.date('*t', timestamp))` across the repeated hour, including negative daylight-saving adjustments. **Remaining limitation:** for an unambiguous date, `isdst` does not force a seasonal correction as C `mktime` can; the timezone's applicable offset is used.
